01 摘要骨架 10 句，每个 Task 至少 1 个数字

[背景 1 句] As [现象/趋势] [变化方向], [研究对象] faces [具体挑战].
[目标 1 句] To explore/evaluate/predict [核心问题], we develop [模型名] model.

[数据 1–2 句] Before modeling, we [数据预处理动作：classified N species into M categories / estimated parameters from X sources].

[Task 1] For Task 1, we established [模型名] based on [基础理论], incorporating [关键创新点]. The results show that [量化结论，含数字].
[Task 2] For Task 2, we calculated [指标1], [指标2] and [指标3] to evaluate [维度1–3]. Results indicate that [趋势/数值结论].
[Task 3] For Task 3, we compared [N] scenarios and found that [具体结论，含数字].
[Task 4/N] We varied [参数] from [A] to [B]; the results show [具体趋势/数值].

[灵敏度 1 句] Sensitivity analysis on [参数名] confirms the model is [stable/robust].
[收尾 1 句] We also discuss [优势] and acknowledge [主要局限], concluding that [总体结论/建议].

Keywords: [模型名], [核心概念1], [核心概念2], [核心概念3]

04 灵敏度 四种做法，按实施成本排序

  1. 单参数三档扫描（OAT）：取 −50% / 原值 / +50%，画三条曲线。评委原话：「as simple as exploring a different range of a parameter」。
  2. 参数重要性排序：扫 3–5 个参数，用 Rank-Oval 图排出谁最敏感。
  3. 蒙特卡洛扰动：给关键参数加扰动分布，报 95% 区间。
  4. Sobol 指数：要区分一阶/交互效应时用，成本最高。

收尾必须有一句结论：the model is stable / most sensitive to X。只画图不写结论等于没做。

05 提交前 1 小时 错一条就可能降档

  • 总页数 ≤ 25（含摘要、目录、附录、参考文献）
  • 每页页眉：Team # + Page X of N
  • 全文无队员 / 学校 / 指导教师姓名
  • PDF 元数据里也无个人信息
  • 摘要每一个数字，正文可查到同一数值
  • 假设列表里的每一条，正文至少用到一次
  • 图表编号连续，正文引用编号与实际一致
  • 参考文献每条都被正文引用，格式全文统一
  • 6 个子问题全部有明确结论段
  • 核对当年 COMAP 规则（页数、AI 使用、匿名）
