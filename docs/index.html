    这七项凭什么这么判

    每一条都对着语料里的分布，不是拍脑袋的「最佳实践」。

    01 / NUMBERS

    数字密度

    O 奖摘要 20–35 个具体数字，M 奖只有 10–15 个。这是两档之间最稳定的差距。

    02 / TASKS

    Task 覆盖

    每个子问题至少一句「方法 + 量化结果」。漏掉 Task 是复筛阶段的直接淘汰项，约 25% 的队伍踩过。

    03 / LENGTH

    长度

    中位数 437 词，四分位区间 350–520。超过 600 词通常意味着背景铺陈过多。

    04 / KEYWORDS

    关键词

    4–5 个，且必须包含你的模型名（GIID、BDS 这类可记忆的标签）。

    05 / SENSITIVITY

    灵敏度

    评委语料里反复出现的一句话：认真做灵敏度的队伍几乎总能脱颖而出。

    06 / LIMITS

    局限性

    最后一句要落地：优势 / 局限 / 结论，三选二也比只写结论强。

    常见淘汰原因 · 发生率

    来自评委点评与语料统计的交叉推断，用于判断先补哪一项。

    摘要无具体数字结论~40%
    无灵敏度分析~35%
    图表无正文解读~30%
    遗漏子问题~25%
    假设与模型脱节~20%
