# 论文工具脚本使用指南

## 概述

本目录包含三个 Node.js 脚本，覆盖 MCM/ICM 论文写作全流程：

| 脚本 | 用途 | 依赖 |
|---|---|---|
| `extract-pdf.mjs` | PDF 论文 → 带页码标记的纯文本 | pdfjs-dist |
| `check-paper.mjs` | 一致性检查（数字/假设/图表/引用） | 无 |
| `parameter-sweep.mjs` | 灵敏度分析（参数扫描 + 敏感性排序） | 无 |

## 前置要求

### 1. 安装 Node.js

确保已安装 Node.js 18+：
```bash
node --version
```

### 2. 安装 pdfjs-dist（仅 extract-pdf.mjs 需要）

```bash
npm install pdfjs-dist
```

## 使用步骤

### 步骤 1：提取 PDF 文本

```bash
node extract-pdf.mjs <论文.pdf> [输出.txt]
```

**示例：**
```bash
node extract-pdf.mjs 2400996.pdf 2400996.txt
```

**输出格式：**
```
### PAGES: 25

=== PAGE 1 ===
Summary
...

=== PAGE 2 ===
Contents
...
```

### 步骤 2：运行一致性检查

```bash
node check-paper.mjs <提取的.txt> [选项]
```

**选项：**
- `--strict` — 严格模式（数字必须 100% 匹配）
- `--report` — 生成详细报告文件（.md）
- `--json` — 输出 JSON 格式（便于程序处理）

**示例：**
```bash
# 标准检查
node check-paper.mjs 2400996.txt

# 生成详细报告
node check-paper.mjs 2400996.txt --report

# JSON 输出
node check-paper.mjs 2400996.txt --json

# 严格模式 + 报告
node check-paper.mjs 2400996.txt --strict --report
```

## 检查项目

### ✓ 通过项（绿色）

| 检查项 | 标准 |
|---|---|
| 页数 | ≤ 25 页 |
| 数字一致性 | 摘要数字在正文中找到 |
| 假设数量 | 4–7 条 |
| 图表数量 | ≥ 8 张图（O 奖标准） |
| 参考文献 | 引用与列表一一对应 |
| 任务覆盖 | 6 个子任务均有回答 |
| 灵敏度分析 | 包含灵敏度分析章节 |
| 优劣势 | 包含 Strengths 和 Weaknesses |
| 匿名合规 | 未发现个人信息 |

### ⚠ 警告项（黄色）

| 检查项 | 说明 |
|---|---|
| 摘要数字未在正文中找到 | 可能是拼写不一致或遗漏 |
| 假设引用不足 | 某条假设在正文中引用少于 2 次 |
| 图表存在但未引用 | 某张图/表在正文中未被引用 |
| 缺少灵敏度分析 | 建议补充 |
| 缺少 Strengths/Weaknesses | 建议补充 |

### ✗ 错误项（红色）

| 检查项 | 说明 |
|---|---|
| 页数超过 25 | 必须压缩 |
| 引用不在参考文献列表中 | 必须修正 |
| 任务遗漏 | 必须补充 |
| 包含个人信息 | 必须删除 |

## 脚本 3：parameter-sweep.mjs（灵敏度分析生成器）

### 用途

对给定的数学模型函数进行参数扫描，自动输出：
- **CSV 结果表**：参数网格 × 输出指标，可直接导入 Excel/Python/Matlab 作图
- **敏感性排序报告**：识别高度敏感/中度敏感/稳健参数

### 使用方法

#### 前置：编写模型文件

模型文件应导出一个函数，接收参数字典，返回输出指标字典：

```javascript
// model.js
export default function(params) {
  const { r = 0.3, K = 100, alpha = 0.5 } = params;
  // ... 模型计算 ...
  return { tb: 206.5, cov: 0.1526, share: 0.5 };
}
```

#### 运行扫描

```bash
# 内联模式（快速测试）
node parameter-sweep.mjs --model=model.js \
  --inline="r=0.1:0.5:0.02;K=100:1000:100;alpha=0.1:1.0:0.1" \
  --out=sweep.csv --report=sweep-report.md

# 配置文件模式（推荐）
node parameter-sweep.mjs --model=model.js --params=params.json \
  --out=sweep.csv --report=sweep-report.md
```

#### 参数配置文件（params.json）

```json
{
  "r":     { "min": 0.1, "max": 0.5,  "step": 0.02 },
  "K":     { "min": 100, "max": 1000, "step": 100 },
  "alpha": { "min": 0.1, "max": 1.0,  "step": 0.1 }
}
```

### 输出示例

```
✓ CSV 写出: sweep.csv  (400 行, 7 列)
✓ 报告写出: sweep-report.md

扫描完成:
  组合数: 400
  数值输出: 3 个
  错误次数: 0
```

**敏感性排序示例：**

| 排名 | 参数 | 敏感性 | 结论 |
|---|---|---|---|
| 1 | `K` | 120.00% | 🔴 高度敏感 |
| 2 | `alpha` | 40.00% | 🔴 高度敏感 |
| 3 | `r1` | 0.01% | 🟢 稳健 |
| 4 | `r2` | 0.01% | 🟢 稳健 |

### 敏感性分级标准

| 变化率 | 级别 | 论文处置建议 |
|---|---|---|
| > 30% | 🔴 高度敏感 | 必须说明测量精度要求 |
| 10%–30% | 🟡 中度敏感 | 建议给出置信区间 |
| < 10% | 🟢 稳健 | 可写 "model is robust w.r.t. X" |

### 与论文的一致性检查

生成的报告自动包含：
- 3 个参数的敏感性排序
- 结论模板（可直接复制到论文）
- 灵敏度章节存在性检查提醒

## 常见问题

### Q1: 找不到 pdfjs-dist？

**A:** 设置环境变量：
```bash
# Windows
set PDFJS_PATH=C:\path\to\node_modules\pdfjs-dist\legacy\build\pdf.mjs

# Linux/Mac
export PDFJS_PATH=/path/to/node_modules/pdfjs-dist/legacy/build/pdf.mjs
```

### Q2: 数字检查误报？

**A:** 检查数字格式是否一致：
- "0.5" vs "0.50" — 视为不同
- "1000" vs "1,000" — 视为不同
- "3.7×10⁵" vs "3.7e5" — 视为不同

建议统一数字格式。

### Q3: 任务覆盖检查不准确？

**A:** 脚本通过关键词匹配（task/question/problem + 数字）。如果论文用其他方式标记任务（如 "Requirement 1"），可能检测不到。建议人工复核。

### Q4: 个人信息检查漏报？

**A:** 脚本只检查常见的个人信息模式（如 "University of ..."）。建议人工检查：
- 队名、校名、队员姓名
- 地理位置暗示（如 "our university in Beijing"）
- 文件元数据（PDF 属性）
