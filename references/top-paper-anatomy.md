## 3 模型创新战术

### 3.1 模型 I：ARIMA-LSTM 混合

**创新点：** 不是"用了 ARIMA"或"用了 LSTM"，而是"结合两者互补"。

```
ARIMA：擅长线性趋势，但缺乏波动性
LSTM：擅长非线性波动，但缺乏趋势
→ ARIMA-LSTM：线性 + 非线性互补
```

**为什么这样设计：**
- ARIMA 捕捉趋势（"the general trend of assets"）
- LSTM 捕捉波动（"the volatility of asset prices"）
- 组合后"both have strengths and weaknesses that complement each other"

**可复制：** 混合模型 = 模型 A 的弱点 + 模型 B 的弱点 → 互补。

### 3.2 模型 II：遗传算法优化

**创新点：** 把交易策略编码为"基因"，用遗传算法搜索最优策略。

```
Gene 1: 投资组合（比特币/黄金/混合）
Gene 2: 交易频率（1/3/5/7/15/30/60 天）
Gene 3: 买入策略（6 种 breakout 策略）
Gene 4: 卖出策略（6 种止损百分比）
```

**为什么这样设计：**
- 策略空间太大，无法穷举
- 遗传算法可以并行搜索多个策略
- 适应度函数 = 收益率（简单直接）

**可复制：** 把决策变量编码为"基因"，用进化算法搜索。

## 5 灵敏度分析（4 种交易成本场景）

### 5.1 设计

```
场景 1：黄金佣金 0.5%，比特币 2%
场景 2：黄金 1%，比特币 1%
场景 3：黄金 0.5%，比特币 1%（同时降低）
场景 4：黄金 2%，比特币 3%（同时提高）
```

### 5.2 结论

```
• 单一资产佣金降低 → 该资产交易频率增加（比特币更敏感）
• 双资产佣金降低 → 收益增加，交易频率增加
• 双资产佣金提高 → 收益最低，交易频率最低
```

**可复制：** 灵敏度 = 多情景 + 明确结论句。

## 7 Strengths & Weaknesses（4 vs 2）

### 7.1 Strengths（4 条）

1. **混合模型互补**：ARIMA + LSTM 兼顾线性/非线性
2. **简单可靠**：仅用历史价格，无需外部数据
3. **遗传算法创新**：优化策略组合 + 生成新策略
4. **双重验证**：策略变化 + 市场环境

### 7.2 Weaknesses（2 条）

1. **历史数据局限**：仅用价格，不考虑基本面
2. **适应度函数单一**：仅测收益率，不考虑风险

**注意：** 这篇论文 Weaknesses 只有 2 条（低于 O 奖标准 3 条），但可能因为其他部分足够强。
