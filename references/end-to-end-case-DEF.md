# D 题：2021 音乐影响力网络（运筹/网络科学）

## 0 概况

| 项 | 值 |
|---|---|
| 题目 | The Development and Evolution of Music |
| 核心问题 | 如何量化音乐家之间的影响力与相似度？ |
| 子任务 | 7 个（影响力网络→相似度→流派区分→"传染性"特征→革命者→动态影响→环境影响） |
| 页数 | 23 页 |
| 模型数 | 4 个链式模型 |

## 1 模型链

```
PageRank 影响力模型（Q1）→ 特征向量相似度（Q2）
        ↓                        ↓
   混合模型：影响力 + 相似度 泛化（Q3/Q4）
        ↓
   继承度指标（Q4：哪些特征"传染"）
        ↓
   演化分析模型（Q5-7：时代革命 + 动态影响 + 社会环境）
```

### 关键设计

**模型 1：改进 PageRank（D 题经典打法）**

```
原版：PR 值从父节点传播到子节点
改进：反转传播方向（子→父），因为"影响力"需要从被影响者反向归因
PR(Vi) = (1-p)/N + p × Σ PR(Vj)/L(Vj)
```

**为什么这是 D 题拿 O 的标准动作：** 网络科学题的核心不是"用了 PageRank"（太多队用），
而是"针对题目结构改进了它"。反转传播方向 1 行代码，却在正文中贡献了
一整节的"为什么这样改"——这是评委要的创新显式化。

**模型 2：双度量交叉验证（相似度）**

```
度量 A：Minkowski 距离 → sim = e^(-d²)
度量 B：余弦距离 → sim = cos θ
结论：两个热力图的色块形状基本一致 → 结果对度量选择不敏感（隐式稳健性验证）
```

**模型 3：继承度指标（自构指标）**

```
将"网络节点连接"与"相似度"结合，构造 Inheriting Degree Index
→ 量化"哪些音乐特征更容易被'传染'"
→ 结论：同样的特征在不同流派中的影响力不同
```

## 2 摘要战术

| 段落 | 动作 | 亮点 |
|---|---|---|
| 背景 | 1 句 + "四模型" 总览 | 数字"4"预告结构 |
| Q1 | PageRank + top 20 | 有具体输出（Table 2） |
| Q2 | 特征向量 + 热力图 | 方法链清晰 |
| Q3/Q4 | 混合模型 + 继承度 | **自构指标命名** |
| Q5-7 | 演化分析 + Beatles 案例 | 具体案例（1960s） |
| 收尾 | 灵敏度 + 优劣势 + ICM Society 信 | 完整 |

## 3 验证方式

- **稳定性验证（非参数扫描）：** 把算法分别跑在全网和 Pop/Rock 子网上，排名一致 → 稳定
- **双度量对比：** Minkowski vs 余弦，热力图形状一致 → 对度量选择不敏感

> **D 题可迁移：** 网络模型不一定要传统灵敏度分析，"子网络/子集一致性"是更自然的验证方式。

# E 题：2023 光污染风险（环境科学）

## 0 概况

| 项 | 值 |
|---|---|
| 题目 | Turn off the lights, Turn on the stars! |
| 核心问题 | 如何量评估光污染风险并设计干预策略？ |
| 子任务 | 4 大任务（度量→应用→策略→案例） |
| 页数 | 25 页 |
| 模型数 | 3 个递进模型（ESE → LPRA → I-ESE） |

## 1 模型链

```
ESE 模型（三子系统风险分解）
  ├─ 经济子系统：Logistic 人口 + 三产业加权 → EC
  ├─ 社会子系统：5 类用地 × 亮度阈值 → SC
  └─ 生态子系统：生物数量 × 光强 → EN
              ↓
LPRA 模型（AHP 基于 Google 搜索指数定权 + K-means 分级）
  → 输出：风险等级 RL ∈ [Slight / Moderate / Serious / Severe]
  → 应用：284 个区域 + 4 个代表城市
              ↓
I-ESE 模型（子系统互联 + 非线性拟合耦合关系）
  → 输出：3 种干预策略 + 最优策略选择 + 20 年效果预测
```

### 关键设计

**数据来源创新：** AHP 的判断矩阵不是拍脑袋，而是**用 Google 搜索指数构造**——
公众关注度作为权重的客观代理。这回应了评委"参数来源透明"的要求。

**四级分类可视化：**

```
Slight(0.0443~0.1678), Moderate(0.1705~0.2542),
Serious(0.2568~0.3698), Severe(0.3976~0.6186)

4 个城市得分：Ordos 0.1332(轻微), Zhaotong 0.1778(中等),
Qingyuan 0.2574(严重), Guangzhou 0.5154(重度)
```

**干预策略量化（F 题式的政策落地）：**

```
广州（策略 I+II）：RL 从 0.5153 → 0.0309（20 年，降 94%）
昭通（策略 II+III）：RL 从 0.1678 → 0.0885（20 年，降 47%）
```

## 2 摘要战术

**数字密度是六题案例中最高的**（4 个区间端点 + 4 个城市得分 + 2 个改善幅度 + 20 年）：

| 数字 | 含义 |
|---|---|
| 284 | 应用区域数 |
| 0.0443~0.6186 | 四级风险区间 |
| 0.1332 / 0.1778 / 0.2574 / 0.5154 | 四城市得分 |
| 0.5153→0.0309 | 广州 20 年改善 |
| 0.1678→0.0885 | 昭通 20 年改善 |
| ±50% | 灵敏度扰动范围 |

**E 题特有战术：** 文学引用开场（Jules Verne《地心游记》），瞬间建立" Turn off the lights, Turn on the stars" 的叙事主题——评委读 200 篇干巴巴的技术摘要后，记得住的是这个标题。

## 3 灵敏度分析

```
成本参数设为原始数据、+50%、-50% 三档 → 风险曲线趋势相似 → 模型稳健
```

> 评委原话佐证：*"Exploration of the sensitivity of a model can be as simple as exploring what happens for a different ranges in a parameter."* —— E 题用最简单的单参数三档扫描就达标了，关键是**结论句**写清楚。

# F 题：2021 高等教育体检报告（政策分析）

## 0 概况

| 项 | 值 |
|---|---|
| 题目 | Health Status and Treatment Plan: A Physical Examination Report for Higher Education |
| 核心问题 | 如何评估各国高教体系的健康度与可持续性，并为薄弱国家开"处方"？ |
| 子任务 | 4 大任务（建立度量→评估多国→选一国深挖→政策建议） |
| 页数 | 25 页 |
| 模型数 | AHP + DEA-Malmquist + Markov 链 |

## 1 "体检报告"框架（F 题最强的叙事创新）

整篇论文用**医学体检隐喻**贯穿：

| 医学概念 | 论文对应 |
|---|---|
| 体检指标 | 6 大因素 14 项指标（投资/可达性/教育水平/科研/公平/吸引力） |
| 正常值范围 | 80% 分位数（K-S 检验验证分布后确定） |
| 综合健康分 | OPG（Overall Point Gain） |
| 体质趋势 | DEA-Malmquist 效率变化 |
| 诊断 | 5 国健康度判定 |
| 处方 | 印度案例：三阶段政策 |
| 疗程预测 | Markov 链政策实施模型 |

**为什么这个隐喻值一个 O：** 它把 4 个松散任务（度量→评估→深挖→政策）
串成一个有记忆点的整体叙事。评委第三轮读完 25 页后还记得"体检报告"这个框架。

## 2 模型链

```
数据（50 国 × 14 指标 × 2009-2018）
  → K-S 检验分布 + 80% 分位定"正常值"
  → AHP 定权 → OPG 健康分
  → DEA-Malmquist 效率趋势 → 可持续性
  → 5 国诊断（US/UK/DE/JP/IN）
  → 印度深挖：现状分析 → 三阶段愿景
  → 靶向政策（短期/中期/长期）
  → Markov 链政策实施预测 + 时间线
  → 现实影响与阻力分析
```

### 关键设计

**权重不是拍脑袋：** AHP 判断矩阵 + K-S 检验确定"正常范围"——每个统计决策都有方法名。

**政策分级（F 题核心）：**

```
短期：降低贫困生教育成本、降低最低工资标准、放宽留学生入学门槛
中期：[经济发展与社会结构过渡]
长期：计划生育、经济结构转型、教育环境改善
```

**政策效果预测：** Markov 链不是用来装点门面的——它回答"政策实施后指标如何随时间演化"，
并画出 Implementation Timeline。

**诊断结论的干净表述：**

```
US：亚健康 + 可持续 | UK：亚健康 + 可持续性差
Germany：完全健康 + 优异可持续 | Japan：不健康 + 可持续
India：不健康 + 不可持续 → 选为深挖案例
```

## 3 F 题可迁移战术

1. **隐喻框架**：把松散任务串成有记忆点的整体叙事（体检、法庭、生态系统…）
2. **政策必须分级**：短/中/长期 + 每条政策标注针对哪个指标
3. **政策效果必须可预测**：Markov 链 / 系统动力学 / 情景仿真，选一个
4. **建议必须"靶向"**：从模型诊断出"病因"，政策逐条对应病因，不能泛泛"加强教育投入"
5. **选案例要有理由**："India has much room for improvement"——不是随便选一国

# 三题横向对比（与 A/B/C 汇总）

| 维度 | D 题（网络） | E 题（环境） | F 题（政策） |
|---|---|---|---|
| 核心方法 | PageRank 改进 | AHP + K-means | AHP + DEA + Markov |
| 创新类型 | 算法改进 | 数据来源创新 | 叙事框架创新 |
| 指标构造 | 继承度 | 风险等级 RL | OPG 健康分 |
| 验证方式 | 子网一致性 | 单参数三档 | 多国交叉对照 |
| 政策落地 | — | 3 策略 + 2 城市案例 | 3 阶段 + Markov 预测 |
| 摘要数字 | ~8 | ~15 | ~10 |
| 叙事亮点 | Beatles 案例 | Jules Verne 引用 | 体检报告隐喻 |

## 六题全景（A-F 终极对照表）

| 题型 | 案例 | 核心模型 | 创新类型 | 验证方式 |
|---|---|---|---|---|
| A 连续 | 2023 干旱 | ODE + 环境耦合 | 机制耦合 | 单种 vs 多种对比 |
| B 离散 | 2022 水资源 | 多目标 + 0-1 规划 | 等效简化 | 分阶段讨论 |
| C 数据 | 2021 大黄蜂 | CA + CNN + 贝叶斯 | 数据驱动 | KL 散度 + 95% CI |
| D 网络 | 2021 音乐 | PageRank 改进 | 算法改进 | 子网络一致性 |
| E 环境 | 2023 光污染 | AHP + K-means | 数据来源创新 | 单参数三档扫描 |
| F 政策 | 2021 高教 | AHP + DEA + Markov | 叙事框架 | 多国交叉对照 |

**结论：** 六大题型拿 O 的"套路"各不相同，但底层的四件事永远一致：
1. **至少一个可命名的创新点**（模型改进 / 指标构造 / 数据洞察 / 叙事框架）
2. **摘要数字密度 ≥ 9 个**（A/B/E 题可以更高）
3. **验证方式与题型匹配**（不是所有题都适合参数扫描）
4. **每个子任务有显式回答标记**
