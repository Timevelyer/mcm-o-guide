# 端到端案例：B 题（离散/优化）2022 水资源分配

## 0 案例概述

**题目：** 2022 MCM Problem B — "Water and Hydroelectric Power Sharing"

**核心问题：** 如何在 5 个西部州之间分配 Lake Mead 和 Lake Powell 的水资源和水电？

**4 个子任务：**
1. 水位固定时，计算各水库供水量和输送时间 + 缺口
2. 水资源紧缺时，给出最佳分配方案和标准
3. 需求大于供给时，如何满足水和电的需求
4. 分析人口/农业/工业/可再生能源/节水措施的影响

**最终成果：** 25 页论文，15 图，10 表

---

## 1 题目拆解

| 子任务 | 输入 | 输出 | 建模方向 |
|---|---|---|---|
| 1 | 两水库水位 + 5 州需求 | 供水量 + 时间 + 缺口 | 优化 + 仿真 |
| 2 | 紧缺约束 | 最佳分配 + 标准 | 多目标 + 评价 |
| 3 | 供需失衡 | 补水方案 | 技术措施 + 分阶段 |
| 4 | 外部变化 | 影响分析 | 敏感性 + 情景 |

**关键识别：** 这是一个**多阶段优化决策**题目。核心是"等效简化 + 多目标 + 分阶段"。

---

## 2 模型链设计

```
数据预处理 → 等效替代模型（水库→倒锥）→ 多目标规划（供需+发电）
                                                    ↓
                                            TOPSIS + 熵权（州优先级）
                                                    ↓
                                            0-1 规划（分阶段分配）
                                                    ↓
                                            补水措施（效率/中水/覆盖）
                                                    ↓
                                            情景影响分析（P4）
```

### 模型 1：等效替代模型（最大创新点）

**核心思路：** 将复杂水库抽象为等效倒锥体

```
Lake Mead：储水量 35 亿 m³，当前水位 1067.65 ft，满载 1220 ft
Lake Powell：储水量 33.3 亿 m³，当前水位 3546.93 ft，满载 3700 ft
→ 抽象为等体积倒锥体，用 V = (1/3)πR²H 反推半径和高度
```

**为什么这样设计：**
- 水库形状复杂，直接建模困难
- 等效锥体保留了储水量这一"根本特征"
- 物理学中的"等效思维"迁移到优化问题——**评委认可跨学科类比**

### 模型 2：多目标规划

**目标函数：** 最大化供水满足率 + 最大化发电量 + 最小化缺口

**约束：** 水位限制、最低发电水位、输水时间、对墨西哥的补偿

### 模型 3：TOPSIS + 熵权法

**用途：** 评价 5 个州的农业和工业重要性，确定供水优先级

**为什么 TOPSIS+EWM：**
- 熵权法客观赋权（不依赖主观判断）
- TOPSIS 排序（逼近理想解）
- 组合使用比单独 AHP 更"客观"——评委偏好

### 模型 4：0-1 规划分阶段分配

**三阶段标准：**
| 阶段 | 水位条件 | 分配策略 |
|---|---|---|
| Stage 1 | 水位充足 | 居民全供 + 农工业 76.77% |
| Stage 2 | 水位下降 | 居民全供 + 农工业 37.8–43.8% |
| Stage 3 | 极度紧缺 | 居民全供 + 农工业 8.8% |

**为什么分阶段：** 现实中水位是动态的，单一策略无法适应。分阶段体现"动态决策"思维。

### 补水措施

| 措施 | 效果 |
|---|---|
| 提高输电效率 | 节水 29,788 m³/天 |
| 中水回用 | 减少需求 6.9×10⁷ m³/天 |
| 聚乙烯薄膜覆盖 | 减少蒸发 5.28×10⁸ m³/年 |

## 4 从这篇论文学到的

### 4.1 成功要素

1. **等效思维创新**：将水库抽象为锥体，物理学方法迁移到优化问题
2. **多方法组合**：等效替代 + 多目标规划 + TOPSIS/EWM + 0-1 规划 + 分阶段
3. **极高数字密度**：摘要 14+ 个具体数字，每个 task 都有量化结果
4. **分阶段动态决策**：体现现实中的适应性，非静态方案
5. **具体措施 + 量化效果**：每条补水措施都有数字效果

### 4.2 可迁移战术

1. **等效简化**：复杂系统→保留根本特征的简化模型（跨学科类比加分）
2. **客观赋权**：熵权法 > AHP（评委偏好"不依赖主观"）
3. **分阶段策略**：动态条件下的多套方案 > 单一方案
4. **措施 + 量化**：每条建议都配数字效果（"节水 X m³"）
5. **任务映射清晰**：每个 Problem 有独立章节，编号对应

### 4.3 B 题特有要点

- B 题常涉及**资源分配/调度/优化**——多目标规划 + 0-1 规划是主力
- **分阶段讨论**在动态约束题中几乎必备
- **评价排序**（TOPSIS/熵权/AHP）用于确定优先级
- 数字密度可以非常高（工程量、流量、成本都是具体数值）

## 5 三题案例对比

| 维度 | A 题（2023 干旱） | B 题（2022 水资源） | C 题（2021 大黄蜂） |
|---|---|---|---|
| 题型 | 连续/机理 | 离散/优化 | 数据洞察 |
| 核心模型 | ODE + 耦合 | 多目标 + 0-1 规划 | CA + CNN + 贝叶斯 |
| 创新类型 | 机制耦合 | 等效简化 | 数据驱动 |
| 摘要数字 | ~15 个 | ~14 个 | ~9 个 |
| 灵敏度方式 | 参数扫描 | 参数扫描 | KL 散度 + CI |
| 评价层 | 指标构造 | TOPSIS/EWM | 贝叶斯推断 |
| 分阶段 | — | ✅ 三阶段 | — |
| 在线更新 | — | — | ✅ Baum-Welch |

**结论：** 不同题型的"拿 O 套路"不同，但**数字密度 + 创新点 + 灵敏度**是共同要求。
