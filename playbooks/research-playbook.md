# 资料与数据检索能力强化手册（全员）

> 基于 6 篇 O 奖论文的参考文献分析，提炼资料检索能力的实战方法。
> 目标：找到权威文献、相关研究思路、公开数据集。

---

## 1 文献检索方法

### 1.1 数据库选择

| 数据库 | 适用领域 | 免费程度 |
|---|---|---|
| Google Scholar | 通用 | 免费 |
| IEEE Xplore | 工程/计算机 | 付费（学校订阅） |
| ScienceDirect | 科学综合 | 付费 |
| SpringerLink | 科学综合 | 付费 |
| PubMed | 生物/医学 | 免费 |
| arXiv | 预印本 | 免费 |
| CNKI | 中文文献 | 付费 |
| 万方 | 中文文献 | 付费 |

### 1.2 关键词搜索策略

**模板：**
```
[核心概念] + [方法] + [应用]
```

**示例（2023 A 干旱）：**
```
关键词 1: "drought" + "plant community"
关键词 2: "soil moisture" + "biomass" + "competition"
关键词 3: "climate change" + "vegetation" + "ODE"
```

**技巧：**
- 用引号精确匹配（"drought resistance"）
- 用 OR 扩展（drought OR aridity）
- 用 AND 缩小（drought AND vegetation）
- 用 * 通配符（climat* → climate, climates）

### 1.3 相关研究思路查找

**方法 1：从参考文献反向追踪**

```
1. 找到一篇相关论文
2. 读它的参考文献
3. 找到更多相关文献
4. 重复 3-5 遍
```

**方法 2：引用网络分析**

```
1. 在 Google Scholar 找到核心论文
2. 点击 "Cited by"
3. 找到引用它的论文
4. 分析引用趋势
```

**方法 3：综述论文**

```
1. 搜索 "review" + [核心概念]
2. 找综述论文
3. 从综述中提取关键文献
```

### 1.4 文献筛选标准

**优先级：**
1. **高影响力期刊**：Nature, Science, PNAS, Water Resources Research, etc.
2. **近期文献**：5 年内（评委看"数据是否最新"）
3. **高引用论文**：被引用 100+ 次
4. **相关方法**：与你的模型方法相关

**排除：**
- 会议论文（质量不稳定）
- 无引用文献（可能是低质量）
- 超过 10 年的文献（除非经典）

## 2 数据集来源

### 2.1 通用数据集平台

| 平台 | 数据类型 | 免费程度 |
|---|---|---|
| Kaggle | 竞赛/研究数据 | 免费 |
| UCI Machine Learning Repository | 机器学习数据 | 免费 |
| World Bank Open Data | 经济/社会数据 | 免费 |
| Our World in Data | 全球统计数据 | 免费 |
| Data.gov | 美国政府数据 | 免费 |
| GitHub Datasets | 开源数据 | 免费 |

### 2.2 专业数据集

| 领域 | 数据集 | 来源 |
|---|---|---|
| 气象 | ERA5 | Copernicus CDS |
| 人口 | UN Population | UN Data |
| 经济 | World Bank | World Bank Open Data |
| 教育 | OECD Education | OECD iLibrary |
| 环境 | EDGAR | IEA |
| 金融 | Yahoo Finance | Yahoo Finance |
| 地理 | Natural Earth | Natural Earth |

### 2.3 数据集获取流程

```
1. 确定数据需求（变量/时间/空间/分辨率）
2. 搜索数据集（Google + 专业平台）
3. 下载数据（注意许可协议）
4. 数据清洗（缺失值/异常值/格式）
5. 数据验证（与已知数据对比）
6. 数据引用（论文中注明来源）
```

### 2.4 数据引用格式

**在论文中引用数据集：**
```
Data source: [Name], [URL], accessed [date].
```

**示例：**
```
Data source: World Bank Open Data, https://data.worldbank.org,
accessed January 2024.
```

## 3 相关研究思路查找

### 3.1 从题目提取关键词

**示例（2022 C 比特币）：**
```
题目关键词：bitcoin, gold, investment strategy, trading
提取关键词：
  - "bitcoin price prediction"
  - "investment strategy optimization"
  - "genetic algorithm trading"
  - "ARIMA-LSTM hybrid"
```

### 3.2 搜索相关论文

**步骤：**
```
1. Google Scholar 搜索关键词
2. 筛选高引用论文（>50 引用）
3. 读摘要 + 方法章节
4. 提取模型思路
5. 记录参考文献
```

### 3.3 模型思路提取

**模板：**

| 论文 | 模型 | 创新点 | 可借鉴 |
|---|---|---|---|
| [Title] | [Model] | [Innovation] | [What to use] |

**示例（2022 C 比特币）：**
```
论文：ARIMA-LSTM for Bitcoin Price Prediction
模型：ARIMA + LSTM 混合
创新点：线性 + 非线性互补
可借鉴：混合模型设计
```

### 3.4 研究思路整合

**方法：**
```
1. 收集 5-10 篇相关论文
2. 提取每篇的模型思路
3. 分类整理（评价/预测/优化/...）
4. 选择适合题目的模型
5. 改进创新（"we develop"）
```

## 4 资料检索工作流（4 天赛制）

### Day 1（选题 + 关键词）

| 时间 | 任务 |
|---|---|
| 0-1h | 读题目 + 提取关键词 |
| 1-3h | Google Scholar 搜索 |
| 3-5h | 筛选高引用论文 |
| 5-8h | 读摘要 + 方法章节 |
| 8-12h | 数据集搜索 + 下载 |

### Day 2（深入 + 模型）

| 时间 | 任务 |
|---|---|
| 0-4h | 读 3-5 篇核心论文 |
| 4-8h | 提取模型思路 |
| 8-12h | 数据清洗 + 预处理 |
| 12-24h | 与建模手协作（模型选择） |

### Day 3（验证 + 补充）

| 时间 | 任务 |
|---|---|
| 0-4h | 验证数据可信度 |
| 4-8h | 补充相关文献 |
| 8-12h | 整理参考文献列表 |
| 12-24h | 与写作手协作（引用格式） |

### Day 4（最终）

| 时间 | 任务 |
|---|---|
| 0-4h | 参考文献格式检查 |
| 4-8h | 数据引用检查 |
| 8-12h | 最终校对 |
| 12-24h | 提交准备 |

## 6 常见检索错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 关键词太宽泛 | 搜索结果太多 | 用引号精确匹配 |
| 只搜英文 | 遗漏中文文献 | 中英文都搜 |
| 不检查引用数 | 低质量文献 | 筛选 >50 引用 |
| 数据不验证 | 结果不可信 | 与已知数据对比 |
| 不引用数据 | 学术不端 | 注明数据来源 |
