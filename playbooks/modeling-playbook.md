## 1 问题拆解 5 步法

### 1.1 第一步：背景理解（30 分钟）

**动作：** 读题目 3 遍，每遍用不同方式理解。

| 遍数 | 方式 | 输出 |
|---|---|---|
| 第 1 遍 | 通读 | 问题是什么 |
| 第 2 遍 | 标注关键词 | 核心概念、约束、目标 |
| 第 3 遍 | 画思维导图 | 子问题之间的逻辑关系 |

**O 奖做法（2023 A 干旱）：**
```
背景：全球气候变化 → 干旱频率增加 → 植物群落如何应对
关键概念：土壤水分、植物生物量、物种竞争、气候周期
子问题：4 个 Task，从单物种到多种群到环境扰动
```

### 1.2 第二步：子问题识别（1 小时）

**动作：** 把题目拆解为 4-6 个子问题，每个子问题有明确的输入/输出/方法。

**模板：**

| 子问题 | 输入 | 输出 | 建模方向 |
|---|---|---|---|
| Task 1 | 数据 X | 结果 Y | 模型 A |
| Task 2 | 结果 Y + 约束 | 优化方案 | 模型 B |
| ... | ... | ... | ... |

**O 奖做法（2022 C 比特币）：**
```
Task 1: 预测资产价格 → ARIMA-LSTM
Task 2: 制定交易策略 → 动态规划
Task 3: 优化策略 → 遗传算法
Task 4: 灵敏度分析 → 交易成本场景
```

### 1.3 第三步：输入/输出定义（30 分钟）

**动作：** 每个子问题明确定义输入变量、输出变量、单位。

**模板：**

| 变量 | 含义 | 单位 | 范围 |
|---|---|---|---|
| $B_i(t)$ | 物种 i 在 t 时刻的生物量 | kg/ha | [0, ∞) |
| $W(t)$ | t 时刻土壤水分 | mm | [0, 500] |

### 1.4 第四步：约束识别（30 分钟）

**动作：** 列出所有显式/隐式约束。

**类型：**
- **物理约束**：非负性、守恒性
- **资源约束**：预算、时间、空间
- **逻辑约束**：先后顺序、互斥性
- **边界约束**：最小/最大值

### 1.5 第五步：目标定义（30 分钟）

**动作：** 明确每个子问题的目标函数。

**模板：**
```
最大化：总收益
最小化：总成本
权衡：风险 vs 收益
```

## 2 假设制定的 4 个来源

### 2.1 来源 1：题目条件

**动作：** 题目明确给出的条件直接转化为假设。

**示例（2022 C）：**
```
题目：$1000 投资 5 年
假设：初始资金为 $1000，投资期为 5 年
```

### 2.2 来源 2：领域知识

**动作：** 从专业领域知识中提取假设。

**示例（2023 A）：**
```
领域知识：植物吸收水分的速率与生物量成正比
假设：水吸收率 = α × 生物量
来源：文献 [7]
```

### 2.3 来源 3：简化需要

**动作：** 为了简化问题而做的假设，必须说明理由。

**示例（2022 C）：**
```
简化：交易可瞬间完成
理由：现实中成交量限制，但为简化编程假设可瞬间成交
```

### 2.4 来源 4：评委偏好

**动作：** 基于评委点评的偏好制定假设。

**评委原话（2009 B）：**
```
"Assumptions must be clearly stated and justified where appropriate."
```

**做法：** 每条假设带 justification（引用文献或说明推理过程）。

### 2.5 假设合理性检验清单

- [ ] 每条假设有 justification
- [ ] 假设不相互矛盾
- [ ] 假设与模型推导一致
- [ ] 假设在正文中被引用（"According to Assumption 2..."）
- [ ] 假设数量 4-7 条（不超过 7）

## 3 模型库速查表

### 3.1 评价类模型

| 模型 | 适用场景 | O 奖频次 |
|---|---|---|
| AHP | 多准则决策 | 高 |
| TOPSIS | 排序评价 | 高 |
| 熵权法 | 客观赋权 | 中 |
| DEA | 效率评价 | 中 |
| Malmquist | 动态效率 | 低 |

**O 奖示例（2021 F 高教）：** AHP + DEA-Malmquist + K-S 检验

### 3.2 预测类模型

| 模型 | 适用场景 | O 奖频次 |
|---|---|---|
| ARIMA | 线性时间序列 | 高 |
| LSTM | 非线性时间序列 | 高 |
| ARIMA-LSTM | 混合预测 | 中 |
| Kalman Filter | 动态系统 | 低 |

**O 奖示例（2022 C 比特币）：** ARIMA + LSTM → ARIMA-LSTM 混合

### 3.3 优化类模型

| 模型 | 适用场景 | O 奖频次 |
|---|---|---|
| 线性规划 | 线性目标 + 线性约束 | 高 |

**O 奖示例（2022 B 水资源）：** 多目标 + 0-1 规划 + 分阶段

## 4 模型选择决策树

```
问题类型？
├─ 连续系统（种群/物理）→ ODE / 差分方程
├─ 离散决策（资源分配）→ 规划（线性/0-1/多目标）
├─ 时间序列预测 → ARIMA / LSTM / 混合
├─ 空间演化 → CA / 反应扩散
├─ 网络关系 → PageRank / 图算法
├─ 评价排序 → AHP / TOPSIS / 熵权
├─ 分类聚类 → K-means / SVM / 贝叶斯
└─ 政策分析 → 系统动力学 / Markov 链
```

## 5 模型检验 4 法

### 5.1 灵敏度分析

**动作：** 参数扫描 + 情景分析 + 蒙特卡洛。

**参考：** [advanced-techniques.md](../references/advanced-techniques.md) §1

### 5.2 稳健性检验

**动作：** 初始条件扰动 + 子网络一致性。

**O 奖示例（2021 D）：** 全网络 vs 子网络排名一致

**动作：** 3 条 Strengths + 3 条 Weaknesses（带解决方向）。

## 7 建模手工作流（4 天赛制）

### Day 1（选题 + 模型框架）

| 时间 | 任务 |
|---|---|
| 0-2h | 读题目 3 遍 + 思维导图 |
| 2-4h | 子问题拆解 + 输入输出定义 |
| 4-8h | 模型选择 + 假设制定 |
| 8-12h | 模型框架草图 + 公式推导 |
| 12-24h | 编程手实现模型 |

### Day 2（模型实现 + 初步结果）

| 时间 | 任务 |
|---|---|
| 0-8h | 模型实现 + 参数调优 |
| 8-16h | 初步结果 + 图表制作 |
| 16-24h | 写作手起草摘要 + Introduction |

### Day 3（灵敏度 + 验证 + 完善）

| 时间 | 任务 |
|---|---|
| 0-8h | 灵敏度分析（2+ 方法） |
| 8-16h | 模型验证（对比 + 检验） |
| 16-24h | 完善模型 + 补充图表 |

### Day 4（写作 + 检查）

| 时间 | 任务 |
|---|---|
| 0-8h | 写作手完成全文 |
| 8-16h | 排版 + 图表美化 |
| 16-20h | 一致性检查（check-paper.mjs） |
| 20-24h | 最终校对 + 提交 |

## 9 常见建模错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 假设无理由 | 筛选扣分 | 每条带 justification |
| 模型无创新 | 终评降级 | "we develop" + 改进 |
| 参数凭空设定 | 可信度低 | 来源：文献/估算 |
| 模型无验证 | 结果不可信 | 至少 1 种验证方式 |
| 灵敏度敷衍 | 降级风险 | 2+ 方法 + 结论句 |

**参考：** [common-errors.md](../references/common-errors.md)

## 10 与编程手/写作手的协作

- 参数表（来源 + 单位）

- 参数扫描
- 图表生成

- 结果解读要点

- 模型章节

- 灵敏度章节
